添加或选择信号

点击「添加信号」创建数字信号或总线；点击画布左侧名称选择已有信号。

2

用鼠标画波形

画笔在上半格画 1、下半格画 0，也可以选定 1 / 0 / X / Z 连续涂画。总线上拖动选定时间范围，在弹窗中输入区间值；双击已有区间编辑。

3

调整时序与样式

直接拖动边沿调整切换时刻，按住 Shift 吸附到网格。右侧设置字体、线宽和过渡时间；填写区间起止时刻后可单独着色。

4

保存与导出

「项目」可保存 JSON 或包含当前图的单文件 HTML。「导出」支持 SVG、PNG 和原生可编辑 PPTX。浏览器会尝试自动保存；重要项目建议主动保存文件。
