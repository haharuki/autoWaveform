# autoWaveform

轻量、离线的数字时序绘图工具。用鼠标绘制数字信号与总线，导出 SVG、PNG 和可编辑 PPTX。

## 使用

双击 **autoWaveform.html**，用浏览器打开即可。

- **绘制**：添加数字信号或总线。画笔上半格画 1、下半格画 0；也可选择 0 / 1 / X / Z 拖动涂画。总线上拖动选择区间，双击已有区间修改值。
- **调整**：默认选择模式，直接拖动边沿；按住 Shift 吸附。右侧设置颜色、线宽、上升/下降时间，或对指定区间着色。时钟生成器支持周期、占空比和相位。
- **样式**：默认黑色细线、Times New Roman 字体。可设置字体、字号、行距、时间轴与网格；X/Z 支持斜线填充或传统虚线。
- **断线**：选择「断线」工具（B）点击插入，拖动移动；属性面板可输入绝对时刻。Delete 删除选中标记，支持撤销。「对齐到全部信号」只添加当前断线点，保留其他标记。

在「画布设置」填写起始、结束时间后统一应用，例如 10–20 ns。改变起点会整体平移波形；缩短跨度会裁去右端内容，可撤销。断线只表示图形省略，不删除时间或信号数据。网格从起点计算；时钟相位是相对起点的延迟。时间单位仅用于标注，不自动换算。

## 导出与保存

SVG 可无损缩放；PNG 支持透明背景和多种倍率，大图可选「自适应」。PPTX 使用原生矢量线条、信号分组与独立文本框，可在 PowerPoint 修改颜色、线宽和字体；断线与填充线同样可编辑。字体未嵌入，其他设备缺少字体时可能替换。

## 开发

需要 Node.js 18+。构建仅使用内置模块，无需 `npm install`：

```sh
npm run build
```

构建生成 `autoWaveform.html` 并嵌入 MIT 许可证。

```text
src/                  HTML、CSS、波形核心与导出器
build.cjs             单文件构建脚本
autoWaveform.html     可直接打开的成品
```

本工具用于时序示意图，不执行仿真或解析 VCD/FSDB。最多 64 路信号，时间跨度 0.25–1000；PNG 大小受浏览器与内存限制。
